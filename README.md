# ASHENWOOD

Portrait mobile fantasy action RPG vertical slice (Godot 4.7).

## Download APK
https://github.com/robb-devo/ashenwood/releases/latest

## Play
- Android: install latest release APK
- PC: `PLAY_ON_PC.bat` (Godot 4.7)

## Controls
- Lower-left stick · Attack lower-right · Talk near NPCs · Menu

## Slice
Title → Village → Woods → Cemetery → Combat (melee/bow/wand) → Bandit + Gravekeeper boss telegraphs → Loot/XP/Gear/Quests/Save
