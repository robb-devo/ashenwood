# ASHENWOOD

Portrait mobile action RPG vertical slice (Godot 4.7).

## Download Android APK

👉 **https://github.com/robb-devo/ashenwood/releases/latest**

Package: `com.ashenwood.game` · Portrait 9:16

## Play on PC

`PLAY_ON_PC.bat` (Godot 4.7) or open `project.godot` → F5

**Controls**
- **Lower-center stick** — drag where you want to walk (not inverted)
- **⚔ Attack** — auto-aims nearby enemies / swings toward facing
- **Talk** — near NPCs
- **Menu** — Character / Inventory (grid) / Equipment / Quests / Upgrade / Settings
