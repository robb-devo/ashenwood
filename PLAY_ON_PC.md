# Play Ashenwood on PC

## Fastest way
Double-click **`PLAY_ON_PC.bat`** in this folder.

## Manual way
1. Install / open **Godot 4.7.x**
2. Import `project.godot`
3. Press **F5**

## Controls
- **Touch / mouse:** drag the lower-left joystick
- **Keyboard:** WASD or arrow keys
- **ATK button:** placeholder (combat comes in Milestone 3)

## Map (Milestone 2)
- Spawn in **Ashenwood Village**
- Path **north** → Whispering Woods
- Path **east** → Old Cemetery
